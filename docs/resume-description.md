# Resume Description

## Project title

Wazuh Control Review Lab

## Resume bullet

- Tested Wazuh file integrity monitoring and security configuration assessment controls in an isolated Ubuntu/Kali lab; investigated a controlled file-change alert, remediated and verified an `/etc/crontab` permission finding, and built a Python reporting tool that validates evidence and separates detected, investigated, corrected, and pending items.

## Short portfolio description

Reviewed two Wazuh security controls using fictional lab data. The project includes reproducible evidence, a documented FIM investigation, an SCA before/after remediation, and a standard-library Python metrics report. Results and limitations are stated explicitly so the work does not claim an attack, attribution, or coverage that was not tested.
